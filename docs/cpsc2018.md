# PTB-XL

Here you can find the documentation on how to test your model on CPSC2018.

Download the dataset from [physionet](https://physionet.org/content/challenge-2020/1.0.2/training/cpsc_2018/) and set `data_folder_cpsc2018` in `configs/train_cpsc2018_config_defaults.yaml`.

The dataset contains signals of varying lengths. To truncate long signals, set `max_length_signal`. After resampling to the target frequency, the pipeline will automatically cut those exceeding the specified number of timepoints.

Run the experiment with `python3 train_cpsc2018.py --config_file <path_to_your_config>`
