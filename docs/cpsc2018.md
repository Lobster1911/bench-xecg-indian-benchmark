# PTB-XL

Here is the documentation on how to test your model on CPSC2018.

Create a new `yaml` configuration file, this will extend the configuration in `config_defaults/train_cpsc2018_config_defaults.yaml`.


Download the dataset from [physionet](https://physionet.org/content/challenge-2020/1.0.2/training/cpsc_2018/).
Then set `data_folder_cpsc2018` in the new config file with the folder where you extracted the data.

## Configuration params

The dataset contains signals of varying lengths.

### max_length_signal

To truncate long signals, set `max_length_signal`. This will be performed after resampling to the model's target frequency

## Run the experiment

Run the experiment with `python3 train_cpsc2018.py --config_file <path_to_your_config>`
